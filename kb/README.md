# kb/ - knowledge base

Verified facts the team learned while working, so nobody has to rediscover them. One topic per file, short, dated.

Good entries: which USB port is which arm on whose laptop, calibration quirks, camera indices and settings that work, training settings that worked or failed (with the run name), hardware fixes.

Not for: ideas (`ideas/`), external research (`research/`), plans and runbooks (`docs/`).

Template:

```markdown
# <topic>

- Date: 2026-11-20
- Verified by: <who / how it was checked>

<the fact, the command or value that works, and what did not work>
```
