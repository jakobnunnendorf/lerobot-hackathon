# docs/ - project documentation

Everything that is not the knowledge base (`kb/`), a decision record (`decisions/`), an idea (`ideas/`) or external research (`research/`): the roadmap, runbooks, the demo script, pitch notes.

No documents that describe the code (architecture walkthroughs, module overviews, API docs). The code describes itself; the reasons behind it go in `decisions/`.

Only `README.md` (setup and SO-101 quick commands) and `CLAUDE.md` (guidance for coding agents) stay at the repo root.
